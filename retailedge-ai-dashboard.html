Solution Architecture

offline-first · hybrid sync · fleet-scale
01 · SENSE

Camera & Sensor Layer

  • Existing IP/CCTV cameras — no rip & replace
  • Shelf-facing cams for SKU vision
  • PoE, on-prem RTSP ingest
  • Optional POS weight / RFID fusion
➜
02 · INFER — ON DEVICE

Edge AI Node · Qualcomm QCS6490 / QCS5430

  • Hexagon™ NPU via Qualcomm AI Engine Direct (QNN)
  • Models compiled & quantized INT8 in Qualcomm AI Hub
  • YOLOv8n person/SKU detection · ByteTrack anonymous tracking
  • Tripwire counting · dwell · heatmaps · planogram match
  • Queue forecaster (GBM on queue time-series)
  • 30 FPS @ ~8 ms · <10 W · runs with zero internet
➜
03 · ACT — IN STORE

Store Edge Gateway

  • MQTT event bus · local time-series DB
  • This dashboard served on LAN
  • Staff alerts: PA / app / handheld
  • POS · inventory · ERP connectors
  • Auto-dispatch replenishment tasks
➜
04 · SYNC — OPTIONAL

Cloud Control Plane

  • Multi-store federation & benchmarking
  • Fleet OTA model updates (AI Hub)
  • Metadata-only uplink (~15 MB/day)
  • Store operates 100% without it

Capability Pillars

mapped 1:1 to the problem statement
🚶

Shopper Analytics

Entry/exit counting, footfall trends by hour & zone, dwell time at displays, live movement heatmaps — all from anonymous tracks.

📦

Inventory Monitoring

Shelf-facing cameras detect low/out-of-stock and planogram drift, then auto-dispatch replenishment tasks to staff handhelds.

🧾

Queue Intelligence

Per-counter queue length, wait & service times, and a forecaster that recommends opening counters before congestion hits.

⚡

Edge AI Processing

All vision runs on Hexagon NPUs at <10 ms/frame. Stores keep operating through internet outages — critical for Tier-2/3 India.

🔒

Privacy-Aware

No face recognition, no stored video, on-chip blurring. Only anonymous metadata events ever leave the device. DPDP-aligned.

📊

Operations Dashboard

Real-time alerts, daily/weekly reports, KPIs for footfall, conversion proxy, shelf health and staff efficiency.

🌐

Scalable Deployment

From a kirana with 2 cameras to chains with 500 stores — POS/ERP integration and centralized multi-store monitoring built in.

💰

Unit Economics

~99.9% less uplink bandwidth, no per-frame cloud GPU cost, sub-10W hardware — payback from reduced stock-outs alone.
